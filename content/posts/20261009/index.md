* France default?

> As of the latest update on 7 Oct 2026 21:46 GMT+0, the **France 5-Year Credit Default Swap (CDS)** value stands at 72.07 basis points. This metric is a crucial indicator used by investors to gauge the credit risk associated with France sovereign debt. This CDS value translates to an implied probability of default of 1.20%, based on a presumed recovery rate of 40%. The recovery rate represents the percentage of the bond's face value that investors expect to recover in the event of a default. The CDS value reached a maximum value of 80.78 (6 October 2026) and a minimum value of 14.9 (17 March 2021).

> [Paul Krugman](https://paulkrugman.substack.com/p/whats-the-matter-with-france): France is on a fiscally unsustainable path. Debt is already very high as a percentage of GDP, and the French government is adding to that debt by running large budget deficits even though there is no emergency like a war, a severe recession, or a pandemic to justify such deficits. Furthermore, France has an aging population, which means that pension costs will, other things equal, grow much faster than revenue.

* news: On October 9, 2026, the entire Deno team announced they’re joining Cloudflare.

> The Deno runtime gets one more year of monthly releases. Bug fixes and security patches only. After that, the Deno team stops developing it. It stays open source.

> Deno Deploy gets six months. Then it shuts down. Paying customers get migration help — to Cloudflare Workers, naturally.

> JSR, the package registry, survives. Its infrastructure moves to Cloudflare.

> rusty_v8 stays supported, and they’re working on folding it into workerd.

> **celld**: One Rust binary. One object storage bucket as its only external dependency. Your existing Workers app, Durable Objects and all, running and scaling on your own machines. Deno built the thing Cloudflare couldn’t. So Cloudflare did the only reasonable thing. They brought them in. Now Ryan Dahl and Bert Belder lead a new effort to merge celld into workerd and make self-hosting Workers a first-class option. Kenton says he’ll personally use it to host Cloudflare OS at home, which is the most engineer sentence ever written.

> A **Durable Object** is basically a tiny server with its own SQLite database, and you talk to it by name. Single-threaded, handles WebSockets, synchronous access to its own database. Easy to reason about.

> workerd, the Workers runtime, is open source. It’s literally the same code Cloudflare runs in production. But its Durable Objects support is single-instance. Great for local testing. Useless for actually scaling anything.

> Ryan points out that Durable Objects are a great fit for agent harnesses: cheap serverless execution, persistent state, WebSockets, nice JS interface. That’s why celld focuses on them. Of course it is. Everything is an agent harness now. 

> Bun joined Anthropic last December. Now (October 2026) Deno joins Cloudflare. VoidZero joined Cloudflare in June 2026.
 
> [Ryan Dahl](https://en.wikipedia.org/wiki/Ryan_Dahl) created Node.js and deno then. Deno was good. It questioned everything Node got wrong — permissions, modules, tooling, TypeScript as a first-class citizen. It forced Node to get better. It was the runtime that said “what if we just… did it properly this time,” and then actually did. It just turned out the runtime was never the destination. Ryan said it himself: Deno, then Deno Deploy, then celld. Each step was him trying to simplify the layer underneath. Deno was a chapter, not the book.

* [OldHorse：2026年诺贝尔医学奖：给大脑装上一个光开关](http://hx.cnd.org/?p=263742)

> 2026年诺贝尔生理学或医学奖颁给了 Karl Deisseroth、Peter Hegemann 和 Georg Nagel，表彰他们在 light-gated ion channels（光门控离子通道）和 [optogenetics（光遗传学）](https://en.wikipedia.org/wiki/Optogenetics)方面的贡献。给指定的神经元装一个可以用光控制的开关

> Hegemann 和 Nagel 等人研究一种叫 channelrhodopsin 的蛋白。这种蛋白很奇怪，光一照，它就可以打开离子通道，让带电离子穿过细胞膜。换句话说，大自然早就造好了一个“光控电开关”。

> Deisseroth 等人后来干了一件非常漂亮的事情：利用基因技术，把这种光敏蛋白放进特定的神经元，然后用光去控制这些神经元的活动。于是原来只能“看脑子在干什么”，变成了可以主动问脑子问题：我把这群神经元打开，动物会怎么样？关掉呢？会不会害怕？会不会产生某种记忆？会不会改变运动、食欲、睡眠甚至社会行为？

> 以前的脑成像，比如 fMRI，很像站在芝加哥上空看夜景：这里亮了，那里暗了，你大致知道哪里热闹。Optogenetics 则有点像你不但能看见哪栋楼亮灯，还能找到其中一个房间，把电灯啪地打开，再看看整个城市发生什么变化。所以今年这个诺奖，我觉得真正重要的不是“用光照脑子”这几个字，而是脑科学从 observation 向 intervention 跨了一大步——从观察相关性，走向实验因果性。诺奖委员会说得很清楚，这套方法使研究者能够研究特定神经细胞怎样参与 memory、feelings 和 behaviour。对研究意识的人，这一点尤其有意思。

> 显微镜发明以前，争论细胞是什么东西可以争几百年；望远镜出来以后，许多关于天体的哲学争论突然变成了可以观察的问题。现在给神经元装上“光开关”，也许我们还不知道它最终能把意识之谜推进多远，但至少以后争论“哪一群神经元究竟干了什么”，可以少靠一点哲学，多开几次灯。
